astro/galaxy/ - Standalone Astronomy Simulations

These are independent JApplet applications in astro/galaxy/. Each has its own main() method, dedicated Canvas class, and can run standalone.

# File App Name Refactored App Description
1 Galaxy.java Galaxy galaxy-sim N-body gravitational simulation with multiple integrators (Runge-Kutta, Hermite, Euler, etc.). Refactored version adds macOS native menu bar.
2 Galaxy3d.java Galaxy 3D galaxy-3d-sim 3D version with leapfrog integrator
3 Saturn.java Saturn saturn-sim Saturn ring/moon dynamics with static electricity effects
4 Belbruno.java Belbruno Transfer belbruno-sim Low-energy lunar transfer trajectories (weak stability boundary)
5 StarSystem.java Star System starsystem-sim Binary/multi-star system with dust, zoom, mass/velocity ratios

7 L4L5.java Lagrange L4/L5 l4l5-sim Trojan asteroid dynamics at Lagrange points with eccentricity
8 Cluster.java Star Cluster cluster-sim Globular/open star cluster N-body simulation
9 DustDisk.java Dust Disk dustdisk-sim Protoplanetary dust disk dynamics
10 EarthCoorbital.java Earth Co-orbital (uses Janus) Earth co-orbital asteroid simulation. Note: main() creates Janus, not standalone.
