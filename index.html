Java Applications

Educational simulations and visualizations originally developed by Professor Robert Vanderbei at Princeton University. These applications have been refactored from Java applets to standalone applications.

Building & Running

Each application includes a Makefile for building:

# Build the JAR file
make jar

# Build macOS .app bundle
make app

# Run the application
make run

Requirements: Java 14+ for running, jpackage for macOS app bundles.
